# Git Keşfi: Streamlit

- **Repo:** streamlit/streamlit
- **Link:** https://github.com/streamlit/streamlit

## Çözdüğü Problem
Python ile geliştirilen veri analizi, simülasyon ve makine öğrenimi modellerini HTML/CSS veya JavaScript bilgisine ihtiyaç duymadan hızla interaktif web arayüzlerine dönüştürmeyi sağlar. Verilerin tarayıcı üzerinde anlık olarak filtrelenmesini ve grafiklerle görselleştirilmesini kolaylaştırır.

## Güçlü Yanları
- Minimum kod satırıyla butonlar, kaydırıcılar (sliders) ve dosya yükleme bileşenleri eklenebilmesi.
- Pandas, Matplotlib ve Plotly gibi yaygın Python veri bilimi kütüphaneleriyle doğrudan uyumlu çalışması.
- Geniş dokümantasyonu ve aktif açık kaynak topluluğu sayesinde kolay öğrenilebilir olması.

## Kendi Projemizde Kullanabileceğimiz Bir Fikir
Grup projemizde işlenen CSV verilerini ve analiz sonuçlarını komut satırı yerine kullanıcıların filtreleme yapabileceği interaktif bir web kontrol paneli (dashboard) üzerinden sunabiliriz.
